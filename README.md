# Portfolio de N’DA YAKPIN YVES JOCELYN

Site de présentation et CV en ligne créé pour une publication GitHub + Netlify.

## Contenu
- `index.html` : page principale du portfolio.
- `style.css` : styles visuels pour la page.
- `IMG_6568.jpeg` : image de présentation.
- `netlify.toml` : configuration de déploiement Netlify.

## Déploiement
1. Publiez le dossier sur un dépôt GitHub.
2. Connectez le dépôt à Netlify.
3. Sélectionnez la branche `main` ou `master`.
4. Déployez sans commande de build (site statique).

## Notes
- Le site est conçu pour être responsive.
- Le contenu utilise votre CV réel : contact, expériences, compétences et formations.
